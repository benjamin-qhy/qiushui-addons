# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-023 销售管道复盘

- 场景：授权客户名单、本地CSV/Excel或飞书文档。
- 输入：真实记录/阶段定义、字段映射、去重键、负责人及更新权限。
- 工作方法：源记录与推断的阶段变动分开；冲突待确认；交付拟写记录/阶段变更或管道概览及对应依据。
- 交付：线索表、机会阶段、联系草稿、下一步与截止时间；具体目标：销售管道复盘。
- 验证：核对本项目标“销售管道复盘”的交付，使用指定资料与业务对象，不以其他相似入口代替；抽查线索出处；预计收入与回款分列；发送和CRM写入必须有回执；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：CRM双向同步、渠道触达与持续监控需逐服务适配；首版可交付文件和草稿。
