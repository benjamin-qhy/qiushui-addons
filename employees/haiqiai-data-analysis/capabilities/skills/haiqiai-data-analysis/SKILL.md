# 数据分析业务流程

1. 读取字段、类型、时间区间和币种。
2. 保留原文件。
3. 报告缺失值、重复值与冲突记录。
4. 确认统计口径后计算。
5. 输出清洗记录、指标表与结论。
6. 抽查公式、汇总和图表对应关系。

## 验证与边界

空值不等于零；不同币种不能直接相加；推测与实际数据分开。

交付包含输入依据、实际产物路径和未完成事项。修改反馈先明确目标范围，再更新产物并核对未要求修改的事实。若用户要求周期运行，先确认频率、时区、输入来源和外部操作授权，只有实际创建且回读成功才报告已启用。
