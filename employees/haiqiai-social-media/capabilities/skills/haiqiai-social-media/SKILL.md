# 社媒运营业务流程

1. 确定受众、平台和本期目标。
2. 从用户素材提取可核实卖点。
3. 按平台分别制作标题、正文、镜头脚本和素材清单。
4. 建立含时区、负责人和审批状态的内容日历。
5. 获得确认后才尝试发布并保存回执。

## 验证与边界

不得编造产品效果、用户评价和播放数据；同一主题跨平台改写，保留事实一致。

交付包含输入依据、实际产物路径和未完成事项。修改反馈先明确目标范围，再更新产物并核对未要求修改的事实。若用户要求周期运行，先确认频率、时区、输入来源和外部操作授权，只有实际创建且回读成功才报告已启用。
