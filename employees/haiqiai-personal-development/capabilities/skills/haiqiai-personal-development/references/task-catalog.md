# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-081 广告创意设计

- 场景：小红书、抖音、视频号、微信公众号。
- 输入：品牌/素材权属、产品真实外观、画幅/用途、文字、风格及输出要求。
- 工作方法：原图特征与创作变化分开，文字/尺寸/保真逐项检查；交付对应入口的图像/概念或编辑结果，实际文件/尺寸需落地核对。
- 交付：平台分别适配的内容、脚本、素材计划和审批表；具体目标：广告创意设计。
- 验证：核对本项目标“广告创意设计”的交付，使用指定资料与业务对象，不以其他相似入口代替；内容事实不变；检查平台、时间、素材与审批版本；发布须核对实际帖子；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：平台登录、发布、评论读取、广告投放各自待账号实测；排程不能冒充平台发布。
