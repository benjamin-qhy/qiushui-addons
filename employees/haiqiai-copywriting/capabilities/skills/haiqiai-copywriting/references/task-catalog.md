# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-039 获客资料

- 场景：授权客户名单、本地CSV/Excel或飞书文档。
- 输入：目标读者、原文/核准事实、用途渠道、语言/长度、CTA/限制。
- 工作方法：来源事实与创作表达分开，不补造客户/数据/免费优惠；交付按目标入口形成可审阅正文/标题/结构及缺项。
- 交付：线索表、机会阶段、联系草稿、下一步与截止时间；具体目标：获客资料。
- 验证：核对本项目标“获客资料”的交付，使用指定资料与业务对象，不以其他相似入口代替；抽查线索出处；预计收入与回款分列；发送和CRM写入必须有回执；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：CRM双向同步、渠道触达与持续监控需逐服务适配；首版可交付文件和草稿。
