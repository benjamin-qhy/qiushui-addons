# 搜索优化业务流程

1. 读取授权HTML、页面或导出数据。
2. 列出页面标题、结构、链接和可索引性问题。
3. 按用户意图组织关键词与内容。
4. 提供逐页修改建议或本地补丁。
5. 验证改动保留业务事实与有效链接。

## 验证与边界

没有数据来源不声称搜索量或排名提升；本地修复不等于已更新线上网站。

交付包含输入依据、实际产物路径和未完成事项。修改反馈先明确目标范围，再更新产物并核对未要求修改的事实。若用户要求周期运行，先确认频率、时区、输入来源和外部操作授权，只有实际创建且回读成功才报告已启用。
