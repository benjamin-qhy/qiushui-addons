# 网站搭建业务流程

1. 明确页面目标与内容来源。
2. 修改既有网站前保存基线。
3. 实现导航、内容、联系入口和响应布局。
4. 运行本地预览并核对链接与关键交互。
5. 交付源码、启动方法及尚未接通的服务。

## 验证与边界

静态演示不等于真实订单、支付或后台；正式部署前确认目标环境。

交付包含输入依据、实际产物路径和未完成事项。修改反馈先明确目标范围，再更新产物并核对未要求修改的事实。若用户要求周期运行，先确认频率、时区、输入来源和外部操作授权，只有实际创建且回读成功才报告已启用。
