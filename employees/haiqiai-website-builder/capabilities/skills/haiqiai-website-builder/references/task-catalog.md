# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-102 网站转化优化

- 场景：中文网站、公众号、国内搜索与授权站点数据。
- 输入：品牌/服务核准事实、原站/目标页面、素材、导航/表单、域名与发布范围。
- 工作方法：页面稿/预览/部署分开；表单/数据收集与静态内容分开；交付指定页面/站点的可审预览或优化清单，保留变更范围。
- 交付：文章、页面修改建议、内容计划或SEO审计；具体目标：网站转化优化。
- 验证：核对本项目标“网站转化优化”的交付，使用指定资料与业务对象，不以其他相似入口代替；本地链接与页面检查；关键词数据注明来源与日期；修改不等于已上线；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：搜索排名、反链、站点监控等数据服务与线上写入待接入；可先分析用户导出。

## AI-122 新产品创意

- 场景：中文品牌素材、商品图、社媒图卡。

- 能力边界：需运行时可用的图像生成/编辑能力或用户指定网页工具；未调用成图不能仅用文字冒充图稿。

## AI-149 库存状态追踪

- 场景：授权店铺导出、本地网站或用户指定国内店铺。
- 输入：目标店铺/产品SKU、订单库存数据、渠道、可执行权限和业务规则。

- 交付：店铺审计、商品草稿、库存/订单异常表或页面文件；具体目标：库存状态追踪。
- 验证：核对本项目标“库存状态追踪”的交付，使用指定资料与业务对象，不以其他相似入口代替；SKU与订单身份稳定；库存和金额可复算；修改与通知核对平台回执；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：店铺订单、商品、购物车、库存接口待逐平台适配；本地表格不能代替后台同步。
