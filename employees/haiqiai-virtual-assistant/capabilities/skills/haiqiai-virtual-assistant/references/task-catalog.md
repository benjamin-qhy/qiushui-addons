# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-018 邮件截止日期转日历

- 场景：QQ邮箱/企业邮箱或授权邮件导出。
- 输入：目标日期、原文日期来源、时区、重复规则、对象标识与冲突偏好。
- 工作方法：区分建议时段、提醒任务和真实日历写入；相对日期需明确基准；交付有日期/时区/行动/来源的计划或提醒草案。
- 交付：邮件摘要、逐封草稿、跟进表或发送计划；具体目标：邮件截止日期转日历。
- 验证：核对本项目标“邮件截止日期转日历”的交付，使用指定资料与业务对象，不以其他相似入口代替；逐封关联原始邮件；检查收件人、附件、退订与去重；实际发送另查发件记录；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：QQ连接器当前只读且真实授权尚未开通；企业邮箱发送及批量营销适配待补，不能宣称已接通。
