# 行政助理业务流程

1. 提取事项、负责人、截止日期和时区。
2. 标注缺失日期而非猜测。
3. 检查日程重叠、前置依赖和循环依赖。
4. 生成可执行排程与会议材料。
5. 确认后写入可用日历并核对回读。

## 验证与边界

纯日期不转为UTC时间点；全天事项保留日期；跨日安排先明确业务时区。

交付包含输入依据、实际产物路径和未完成事项。修改反馈先明确目标范围，再更新产物并核对未要求修改的事实。若用户要求周期运行，先确认频率、时区、输入来源和外部操作授权，只有实际创建且回读成功才报告已启用。

## 完整业务目录

遇到具体业务需求，按编号或中文标题查阅 [任务目录](references/task-catalog.md)，选择匹配的输入、交付和验收要求。共 12 项入口，目录覆盖不代表外部动作已接通。若跨越基础岗位职责，仍按对应目录处理或明确缺失能力，不因岗位名称忽略原需求。
