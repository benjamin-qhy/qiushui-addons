# 国内业务任务目录

按业务标题查找，只读取相关小节。编号是需求追踪标识。每项先核对实际工具与授权；没有平台能力时交付可用草稿，并明确剩余操作，不宣称已完成外部动作。

## AI-214 发布招聘职位

- 场景：授权简历、招聘需求和用户指定国内招聘渠道。
- 输入：岗位硬条件、合法评估标准、候选人授权材料、地区时区与流程阶段。
- 工作方法：证据与推测分开；简历缺失不编，职位匹配与偏好不混作事实；交付岗位/候选清单、匹配证据、面试或入职草案与缺项。
- 交付：岗位稿、候选人对比表、面试问题或邀约草稿；具体目标：发布招聘职位。
- 验证：核对本项目标“发布招聘职位”的交付，使用指定资料与业务对象，不以其他相似入口代替；同一标准逐人引用经历；缺项不推断；平台发布和邀约必须另有回执；保存可打开的交付文件或可检查的正文；执行一次局部修改并复核保留项；原需求包含周期或外部动作时，基础交付和完整闭环分别记录，不互相替代。
- 能力边界：招聘平台采集、发岗、邀约与持续同步未接通；首版基于授权资料交付。
